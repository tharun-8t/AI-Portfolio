# Student Expense Tracker

A beginner-friendly Python expense tracker built to practice programming fundamentals and data handling.

## Features

- Add expenses
- View all expenses
- Delete expenses
- Calculate total spending
- Calculate spending by category
- Validate expense amounts
- Save expenses permanently using JSON

## Technologies

- Python
- JSON
- Git
- GitHub

## How to Run

Open the terminal inside the `expense-tracker` folder and run:

```bash
python expense_tracker.py
